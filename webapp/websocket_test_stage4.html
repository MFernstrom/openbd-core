Stage 4: allowPublish() and beforePublish() Hooks Test

This test demonstrates the allowPublish() and beforePublish() CFC hooks that control message publishing.

The moderatedChannel only allows users with role="moderator" to publish messages.

Disconnected
Current Role: user

Test 1: Subscribe as Regular User (No Role)

Subscribe without specifying a role. Publishing will be denied.

Test 2: Try to Publish as Regular User (Should Fail)

Attempt to publish a message without moderator role. The allowPublish() hook will reject it.

Test 3: Subscribe as Moderator

Subscribe with role="moderator". Publishing will be allowed.

Test 4: Publish as Moderator (Should Succeed)

Publish a message with moderator role. The beforePublish() hook will add timestamp, badge, and sanitize content.

Expected Results:

  • ✅ Test 1 should SUCCEED (subscription allowed)
  • ❌ Test 2 should FAIL (publish denied - no moderator role)
  • ✅ Test 3 should SUCCEED (subscription with moderator role)
  • ✅ Test 4 should SUCCEED and message should be transformed:
    • Server timestamp added
    • Moderator badge added
    • HTML tags sanitized (< and > escaped)
    • Text length added

Note: When subscribing with a different role, the test will automatically unsubscribe first. This allows you to run all tests in sequence without reloading the page:

  • Test 1 → Subscribe as user (stays subscribed)
  • Test 2 → Publish as user (uses subscription from Test 1)
  • Test 3 → Auto-unsubscribe, then subscribe as moderator (stays subscribed)
  • Test 4 → Publish as moderator (uses subscription from Test 3)
