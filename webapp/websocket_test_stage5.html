🧪 Test 1: Room-Based Filtering (canSendMessage)

Steps:

  1. Click "Subscribe All Users"
  2. User A sends message to "lobby" → Both A and B receive (same room), C does NOT (different room)
  3. User C sends message to "vip" → Only C receives, A and B do NOT

Expected: Messages only delivered to users in the same room (canSendMessage filters)

🧪 Test 2: Email Privacy (beforeSendMessage)

Steps:

  1. Add email to User A's message: alice@example.com
  2. User A sends to lobby
  3. Check messages: A sees real email, B sees "[HIDDEN]"

Expected: Email addresses hidden from non-sender users

🧪 Test 3: Phone Privacy - Admin Only (beforeSendMessage)

Steps:

  1. User C (admin) sends message to lobby with phone: 555-1234
  2. Check messages: C sees phone, A and B see "[ADMIN ONLY]" (they're not admins)

Expected: Phone numbers only visible to admins and sender

🧪 Test 4: "isYou" Flag (beforeSendMessage)

Steps:

  1. User B sends message to lobby
  2. Check User B's panel: Message should be highlighted/bold (isYou=true)
  3. Check User A's panel: Normal display (isYou=false)

Expected: Each user sees their own messages differently
