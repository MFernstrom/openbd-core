🧪 Test Scenarios for Message Isolation

  1. Channel Isolation Test:
    • Subscribe to ONLY testChannel in Tab 1
    • Subscribe to ONLY chatChannel in Tab 2
    • Publish to testChannel - should only appear in Tab 1
    • Publish to chatChannel - should only appear in Tab 2
  2. Multi-Channel Subscription:
    • Subscribe to ALL channels in Tab 1
    • Subscribe to ONLY testChannel in Tab 2
    • Publish to each channel - Tab 1 should see all, Tab 2 only testChannel
  3. Dynamic Unsubscribe:
    • Subscribe to all channels
    • Unsubscribe from chatChannel
    • Publish to chatChannel - should NOT receive
    • Publish to testChannel - should still receive
  4. Multi-Tab Broadcast:
    • Open 3 tabs, subscribe all to testChannel
    • Publish from Tab 1 - all 3 should receive
    • Verify each tab shows sender's client ID
