Stage 7: Comprehensive Premium Chat System

🎯 What This Test Demonstrates:
This is a complete real-world example showing all 5 Channel Listener hooks working together:
  • allowSubscribe(): Authentication, tier validation, VIP room access
  • allowPublish(): Ban checking, tier restrictions, rate limiting (5s/2s/1s)
  • beforePublish(): Sanitization, timestamps, message length limits (100/500/2000)
  • canSendMessage(): Room filtering, premium feature filtering, block lists
  • beforeSendMessage(): Privacy controls, tier-based features, custom per-user views

🆓 Alice (Free Tier)

User ID: alice
Tier: FREE
Room: lobby
Limits: 100 chars, 5s cooldown, lobby only

💎 Bob (Premium Tier)

User ID: bob
Tier: PREMIUM
Room: premium
Limits: 500 chars, 2s cooldown, any room except VIP

👑 Charlie (VIP Tier)

User ID: charlie
Tier: VIP
Room: vip
Limits: 2000 chars, 1s cooldown, all rooms

🧪 Test Scenarios (Run in Order)

Test 1: Subscribe with Tier Validation (allowSubscribe)

  1. Click "Subscribe All Users"
  2. All three users should subscribe successfully
  3. Check logs: Alice=free/lobby, Bob=premium/premium, Charlie=vip/vip

Test 2: Room-Based Filtering (canSendMessage)

  1. Alice sends to lobby → Only Alice sees it (others in different rooms)
  2. Bob sends to premium → Only Bob sees it
  3. Charlie sends to VIP → Only Charlie sees it

Test 3: Message Length Limits (beforePublish)

  1. Alice: Type 150 characters → Message truncated to 100 chars with "[truncated]"
  2. Bob: Type 600 characters → Message truncated to 500 chars
  3. Charlie: Type 2500 characters → Message truncated to 2000 chars

Test 4: Rate Limiting (allowPublish)

  1. Alice: Send message → Immediately send again → Second should FAIL (5s cooldown)
  2. Bob: Send → Wait 2s → Send again → Should succeed (2s cooldown)
  3. Charlie: Send → Wait 1s → Send again → Should succeed (1s cooldown)

Test 5: Premium Features (canSendMessage + beforeSendMessage)

  1. Bob clicks "Send Premium Feature" → Message includes attachment
  2. Bob sees: Real attachment info
  3. Alice sees: "[PREMIUM FEATURE - Upgrade to view]" (free tier)

Test 6: Privacy Controls (beforeSendMessage)

  1. Messages include email field (alice@example.com, etc.)
  2. Each user sees their own email, but others see "[HIDDEN]"
  3. Phone numbers: Only sender + VIPs see real number, others see "[VIP ONLY]"

Test 7: Sanitization (beforePublish)

  1. Try sending: "<script>alert('hack')</script>"
  2. Should be sanitized to: "&lt;[removed]&gt;alert('hack')&lt;/[removed]&gt;"
