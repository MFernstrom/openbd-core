  2. Open this page in Tab 2: Set userId=bob, room=premium, tier=premium
  3. Open this page in Tab 3: Set userId=charlie, room=vip, tier=vip

Test 1: Tier Validation (allowSubscribe)

  1. All three users should subscribe successfully
  2. Try subscribing charlie to "lobby" with tier "free" to VIP room → Should FAIL (VIP room requires VIP tier)

Test 2: Room-Based Filtering (canSendMessage)

  1. Tab 1 (alice) sends to "lobby" → Only Tab 1 receives
  2. Tab 2 (bob) sends to "premium" → Only Tab 2 receives
  3. Tab 3 (charlie) sends to "vip" → Only Tab 3 receives

Test 3: Message Length Limits (beforePublish)

  1. Tab 1 (alice=free): Click "Send Long Message" → Should truncate to 100 chars
  2. Tab 2 (bob=premium): Click "Send Long Message" → Should truncate to 500 chars
  3. Tab 3 (charlie=vip): Click "Send Long Message" → Should truncate to 2000 chars

Test 4: Rate Limiting (allowPublish)

  1. Tab 1 (alice=free): Send message → Immediately send again → Second should FAIL (5s cooldown)
  2. Tab 2 (bob=premium): Send → Wait 2+ seconds → Send again → Should succeed
  3. Tab 3 (charlie=vip): Send → Wait 1+ seconds → Send again → Should succeed

Test 5: Premium Features (canSendMessage + beforeSendMessage)

  1. Tab 2 (bob=premium): Check "Include Premium Feature" and send to "lobby"
  2. Tab 1 (alice=free, lobby): Should see "[PREMIUM FEATURE - Upgrade to view]"
  3. Tab 2 (bob, if in lobby): Should see actual attachment info

Test 6: Privacy Controls (beforeSendMessage)

  1. Tab 1 sends to lobby → Tab 1 sees own email, others see "[HIDDEN]"
  2. Phone numbers: VIP users + sender see real number, others see "[VIP ONLY]"

Test 7: HTML Sanitization (beforePublish)
